# ARCHIVE

Owner: Documentation maintainers
Scope: Non-binding historical narrative that is useful for archaeology but does not describe current behavior or impose current instructions.
Verified against: 4f51fdd (2026-08-01)

Accepted and superseded ADRs remain the primary durable history because they record context, decisions, amendment edges, and consequences. This directory is only for historical narrative that does not qualify as an ADR.

Living contracts must describe the implementation and rules that exist now. Move obsolete rollout notes, redesign chronology, resolved investigations, and replaced workflows here or delete them when they have no continuing value. Never route implementation work through archived material, and never use it to override `CRITICAL_INVARIANTS.md`, accepted ADRs, or an owning living contract.
