## Provider Transport And Limits

Each accepted provider runtime resolves one immutable response deadline from its versioned binding: the optional model override wins over the connection default. Admin supplies whole seconds from 5 through 900; storage/runtime use integer milliseconds; new and legacy/missing connections use 300 seconds. The runtime starts one absolute model-round timer and passes the same effective value through each provider HTTP client, buffered success/error body read, OpenAI background lifecycle, and SSE idle/absolute guards. A streaming transport may release its header/body exchange timer after returning the SSE response, but the enclosing model-round timer and stream parser retain the same ceiling. Cancellation remains a distinct parent abort. No application timing environment variable or adapter-local 30-second cap participates. External provider, reverse-proxy, and platform deadlines remain outside AIQSA's guarantee.

A validated client-Search call supplies the earlier of its immutable revision-owned 5-second to 15-minute invocation budget and its technical provider model's effective deadline. Both budgets and the result are inspectable; neither is silently undercut by a transport default. Untrusted buffered bodies still share the `AIQSA_PROVIDER_RESPONSE_MAX_BYTES` cap (16 MiB by default), are cancelled on timeout/overflow, and feed only sanitized error previews. Streaming retains independent size limits of 4 MiB/event, 64 MiB total raw wire, and 8 Mi retained characters by default; visible answer text and independently accumulated reasoning, tool-argument, signature, and citation structures are checked before retention. All adapters measure the same bounded streaming contract while preserving immediate valid deltas and provider terminal semantics; they never truncate or automatically retry an overflowed response.

`lib/server/providers/types.ts` is the code owner of the adapter boundary: `NormalizedRunRequest` is the normalized/persistable request shape and `ProviderRunRequest` adds resolved private attachments plus tool/streaming execution controls. Do not copy those interfaces into living prose; update the exported types and their tests together. Each adapter emits normalized events and returns a `ProviderRunResult` with safe provider-specific request/response previews, usage, and artifacts.
