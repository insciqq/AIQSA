# AIQSA unified Providers mockup v1

This review-only concept addresses the proposed information-architecture change without changing the runtime UI:

- `Setup`, `Connections`, and `Run profiles` are persistent peer tasks in one Providers workspace;
- the direct key path remains visible on `Setup`;
- a configured disabled provider reads as `Disabled`, not `Needs attention`;
- `Manage OpenAI connection` is a prominent secondary action rather than a small Advanced disclosure;
- custom compatible setup remains a peer action beneath provider selection.

The current Quick/Advanced runtime separation remains in place until the operator approves a direction. The source prompt is preserved under `prompts/` and the earlier concept/mockup sets remain unchanged.
