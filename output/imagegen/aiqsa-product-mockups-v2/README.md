# AIQSA product mockups v2

This set explores the corrected revamp direction after the first implementation review:

- centered composer for an empty new chat;
- subject-based Control Center navigation with no `Personal` category;
- direct Provider -> API key -> Test & Save setup;
- full-width clickable user directory without a permanent detail pane;
- combined `Access & groups` destination;
- dedicated, secondary Advanced provider page without nested sidebars.

The original v1 concept set remains unchanged in `output/imagegen/aiqsa-product-mockups-v1/`.
